# WARDOGS Item Index

WARDOGS Item Index is a community-made reference for the game's equipment, progression and economy. It brings item data, comparisons and weapon build tools into one place, with a layout inspired by the in-game shop.

## What you can expect

- Browse weapons, attachments, gear and ammunition, including stats, prices and unlock requirements.
- Compare items and see which values come out ahead for individual stats.
- Experiment with compatible attachments in Build Lab and compare stock and modified weapon values.
- Explore the available armour, vehicle, ammunition and component data.
- Look up class progression, unlock costs and economy information.

## Sources

Information is compiled from publicly available WARDOGS data, gathered and combined into a format that is easier to browse and compare.

## AI assistance

GPT-6.1 Sol was used to gather and combine the data, connect related items and stats, and design and build the Index. AI-assisted work can contain mistakes, including incorrect values, interpretations or comparisons.

## Important notice

WARDOGS and its developers may change items, balance, prices, unlocks and other game systems at any time. Updates to this site may lag behind the game.

This is an unofficial reference and should not be treated as a source of truth. Check the game and official WARDOGS information when accuracy matters.
